# Nykaa-Capstone-Project
Playwright Automation Testing Capstone Project using Nykaa website
## Project Overview
This project focuses on automating the major functionalities of the Nykaa beauty and skincare website using Playwright automation framework.

## Technologies Used
- Playwright
- JavaScript
- Node.js
- GitHub

## Modules Covered
- Homepage Validation
- Product Search
- Filter & Sorting
- Product Details
- Cart Management
- Wishlist Management
- Checkout Validation
- Responsive UI Testing
